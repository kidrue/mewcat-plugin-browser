# 三花猫加载动画：造型与动作提示词

## 造型设计提示词

以用户提供的三花猫图片为唯一造型参考。侧面朝右，奶白色皮毛，芥末黄与灰绿色斑块，暖灰细线，圆润肚子，小眼睛，长而柔软的上翘尾巴。保持朴素、轻盈的手绘感和透明背景。小尺寸仍能认出耳朵、侧脸和四肢。不要添加围巾、星星、大眼睛、蓝色描边或其他配饰。

## 动画设计提示词

制作原地向右奔跑的轻快循环，镜头固定，角色体积稳定。以猫科动物的伸展与收拢为核心，安排伸展腾空、前爪接地、屈肘缓冲、四肢收拢、后足支撑、蹬地伸展。肩部和髋部保持连接，膝肘弯曲带动脚掌沿弧线移动。支撑期脚掌向后移动，回收期脚掌抬起并向前收回。远近侧四肢略微错拍，不能像四根杆子同步摆动。重心随落地轻压、随蹬地抬起，尾部弯曲稍后跟随身体，末端有柔和的惯性。首尾姿势和速度相接，不在循环接缝处顿一下。

避免：整条腿绕固定点机械旋转、匀速上下漂浮、过大的整体缩放、脚掌穿过身体、忽快忽慢的随机动作、附加闪光和密集粒子。

## 关键姿势

| 周期位置 | 动作重点 |
| --- | --- |
| 0% / 100% | 伸展腾空，身体轻微拉长，前后脚分开 |
| 16% | 前爪向下接地，重心开始下降 |
| 32% | 前肢屈曲承重，后腿向腹下收回 |
| 50% | 四肢收拢，脚掌弯曲，身体提起 |
| 68% | 后脚向下伸展支撑，前肢抬起 |
| 84% | 后脚向后蹬出，前肢向前伸展 |

默认周期为 0.72 秒。四肢与尾巴采用相同拓扑的曲线关键帧连续形变，身体只使用轻微位移、俯仰和压缩。系统启用减少动态效果时显示静态参考姿势。

预览包含正常播放、慢速、暂停、逐帧定位及关键姿势展示，检查重点是落脚节奏、关节弯曲、轮廓连续和循环接缝。
