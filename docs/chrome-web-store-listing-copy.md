# mewCat Chrome 扩展商店文案与优化建议

核对日期：2026-09-14。依据当前工作区源码撰写；未核验线上商店版本、排名或开发者后台数据。发布时应以实际上传版本的功能为准。

## 推荐定位

面向需要阅读外语文章、技术文档和海外资讯的中文用户，以「网页双语阅读」为主卖点，以划词翻译、图片翻译和可选 AI 能力补充使用场景。

建议标题突出品牌与主要用途，避免把所有功能和模型品牌都塞进标题。以下关键词分布是文案建议，不代表 Google 公布的字段权重或排名公式。

## 可直接使用的商店文案

### 扩展名称

```text
mewCat 译趣喵 - 网页翻译与双语阅读
```

### 简短说明

```text
网页双语翻译、划词翻译和图片翻译，支持 Google 翻译及自定义 AI 模型。阅读外语文章、技术文档与海外资讯，更少切换，更专注内容。
```

摘要须控制在 132 个字符以内，优先让用户一眼理解用途。[官方文案指南](https://developer.chrome.com/docs/webstore/best-listing)

### 详细产品说明

```text
读外语网页，让译文就在原文身边。

mewCat（译趣喵）是一款 Chrome 网页翻译扩展，提供网页双语翻译、划词翻译和图片翻译。无论是阅读外语文章、查阅技术文档，还是浏览海外资讯，都能在当前网页中查看译文，减少来回复制与切换。

主要功能

• 网页双语阅读
在原文附近显示译文，方便对照阅读，并尽量保留网页原有排版。通过页面悬浮按钮开启或关闭翻译，让阅读保持连贯。

• 划词翻译
选中单词、句子或段落即可查看翻译。适合快速理解陌生表达、技术术语与文章片段。

• 图片翻译
配置支持图片识别的 AI 视觉模型后，可识别并翻译网页图片中的文字，在图片上查看译文。适合阅读外语配图和图片中的说明内容。

• 自选翻译服务
默认 Google 翻译通道无需填写 API Key。也可配置自己的 API Key，接入 OpenAI、DeepSeek、Gemini 等支持的服务，并按需设置模型和自定义接口地址。

• AI 辅助理解
配置生成式 AI 模型并开启相应功能后，可使用网页总结与划词概念解释，帮助提炼文章要点、理解陌生概念。

• 按阅读习惯设置
选择目标语言、调整译文样式，并设置网站翻译规则，让翻译更贴合自己的浏览习惯。

开始使用

1. 安装扩展后，打开需要阅读的外语网页。
2. 使用页面悬浮按钮开启网页翻译，或选中文字进行划词翻译。
3. 如需 AI 翻译、总结或概念解释，在设置中添加相应模型并开启所需功能；图片翻译需另外选择视觉模型并开启图片翻译按钮。

使用说明

翻译服务需要网络连接。默认 Google 翻译通道的可用性可能受网络、限流或服务变化影响。AI 功能需要配置可用的 API Key；服务商可能按其规则收取费用。

执行翻译或 AI 分析时，相关文本或图片会发送给对应服务商处理。图片识别、译文质量及页面适配效果取决于模型能力、图片清晰度和网站结构。
```

上述使用说明是功能与服务条件提示，不替代完整隐私政策。

## 优先优化事项

### 1. 先补齐名称与摘要

当前 `wxt.config.ts` 的 `manifest.name` 是 `mewCat`，配置中未显式提供 `manifest.description`。建议将选定的标题和摘要落实到扩展包，并核对构建后的 manifest。详细说明则填写在 Chrome Web Store 开发者后台。

这是源码配置观察，不代表已经确认线上商店缺少摘要。本次仅提供文案，没有修改扩展配置或发布内容。

### 2. 用真实效果图提高安装意愿

建议准备五张 1280×800 截图，每张只讲一个用途：

| 顺序 | 画面                                 | 建议短标题             |
| ---- | ------------------------------------ | ---------------------- |
| 1    | 同一篇文章的原文与译文同屏           | 原文译文，一起读       |
| 2    | 选中词句后显示翻译浮窗               | 选中词句，快速看懂     |
| 3    | 一张文字清晰的图片及实际翻译覆盖效果 | 图片里的文字，也能读懂 |
| 4    | 文章正文与真实生成的总结             | 长文阅读，先抓重点     |
| 5    | 翻译服务选择和译文样式的真实界面     | 翻译方式，由你选择     |

涉及 AI 的截图应简短注明「需配置 AI 模型」或「需配置视觉模型」。保持 mewCat 的蓝白品牌风格，让实际使用效果占据主要画面。

同时准备 440×280 小型宣传图和 1400×560 横幅宣传图；后者是进入首页横幅展示的素材前提，提交素材不代表会被选中。截图与宣传图的要求见[官方图片规范](https://developer.chrome.com/docs/webstore/images)。

### 3. 把首次成功翻译做顺畅

建议围绕「安装 → 打开示例网页 → 完成首次翻译」检查流程。优先解决默认通道失败、按钮不好找、译文挤乱排版等实际问题，再考虑增加功能。AI 配置应清楚说明何时需要 API Key、在哪里填写，以及图片翻译需要单独选择视觉模型。

这些是提升使用体验的建议。Google 表示排名会考虑评分和安装、卸载等使用统计；没有公开可保证名次的公式。[官方发现与排名说明](https://developer.chrome.com/docs/webstore/discovery)

### 4. 完成英文体验，再考虑 Featured 自荐

建议先做英文界面、扩展元数据、商店描述和截图的完整本地化。当前源码中未发现 `_locales` 目录；仅补一段英文说明，不能视为已经具备英文产品支持。商店语言与扩展内的 locale 对应，具体流程见[商店本地化指南](https://developer.chrome.com/docs/webstore/cws-dashboard-listing)。

官方目前提供 Featured 徽章自荐入口，条件包括公开上架、英文支持、无未解决违规，以及核心功能无需额外凭据或付费即可使用。可据此准备申请，但徽章、自荐与首页编辑推荐是不同事项，不能保证首页展示。详见[官方徽章与自荐条件](https://developer.chrome.com/docs/webstore/discovery)。

### 5. 补齐信任信息与真实反馈入口

提供有效的官网、支持页面及隐私政策，并验证自有域名。域名验证有助于展示官方链接，不等同于自动获得 Established Publisher 徽章。[后台字段说明](https://developer.chrome.com/docs/webstore/cws-dashboard-listing)

隐私披露需覆盖实际发送给服务商的内容，并核对生产构建启用的错误监控。当前代码包含条件启用的 Sentry，因此不应直接宣传「零数据上传」「完全本地」或「不收集任何数据」。商店声明应与实际行为、隐私政策一致。[官方隐私最佳实践](https://developer.chrome.com/docs/webstore/best-practices)

可以温和邀请用户留下真实评价，提供明确的反馈入口并处理问题。不要以奖励换取评分、评论或安装。[官方反滥用政策](https://developer.chrome.com/docs/webstore/program-policies/spam-and-abuse)

### 6. 用数据判断优化有没有作用

建议先记录两周基线，再分批调整标题摘要、首张截图或引导流程；低流量时延长观察期。固定语言、地区和关键词，记录观察到的搜索位置，同时看商店曝光、安装、卸载和评论变化。前后对比会受到时间与流量来源影响，不能直接证明某一改动导致排名上涨。

后台可查看安装、卸载和曝光等报告；其中 Users 指标反映安装情况，不能直接当作活跃用户数。[官方商店数据说明](https://developer.chrome.com/docs/webstore/metrics)

站外可制作真实的「如何双语阅读技术文档」「如何翻译网页图片」教程，链接到商店页面，帮助有相应需求的用户找到扩展。
