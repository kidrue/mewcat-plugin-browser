# 页面总结快捷键方案（已确认）

## 目标与交互

- 在基础设置的“页面总结”区域增加“打开总结快捷键”，推荐默认 `Alt+S`。
- 点击配置框后录制单键或组合键，支持恢复默认和清除；清除表示禁用快捷键。
- 按快捷键直接打开现有总结弹窗。尚未生成时先展示加载状态，再生成总结；已有结果则直接展示，生成中则复用当前任务。
- 快捷键独立于“自动总结页面”开关；扩展总开关关闭时不触发。临时隐藏总结按钮后仍可通过快捷键打开。
- 输入框、可编辑区域、输入法组合输入和长按重复事件不触发；遵守现有网站排除规则，对无法总结的情况展示原因。
- 与段落翻译快捷键重复时提示冲突并拒绝保存；两个配置入口都进行检查。
- 旧配置升级或导入配置出现重复快捷键时，优先保留已有段落翻译快捷键，将总结快捷键禁用，避免新默认值抢占旧设置；可在设置页重新录制总结快捷键。

## 可行性与技术选型

现有 `PageSummaryController.start("manual")` 已实现弹窗打开、结果复用和任务去重，可直接复用；不需要新增权限、依赖或后台服务。

推荐页面内监听键盘事件，沿用段落翻译的配置与按键编码方式。优势是可直接在扩展设置页录制并即时生效；限制是浏览器或系统拦截的按键可能无法触发。

另一个方案是使用 Chrome 扩展命令，由浏览器管理快捷键，但配置入口会转移到浏览器快捷键页，与现有段落翻译配置体验不一致，因此不推荐本次采用。

## 实现范围

- 将 `components/ParagraphShortcutInput/index.tsx` 的录制控件整理为可复用形式，保留现有段落翻译入口，并用于页面总结。
- 在 `types/config.ts`、`types/extensionConfigSchema.ts`、`state/constants.ts` 增加 `pageSummaryShortcut`；空字符串表示禁用，旧配置使用推荐默认值。
- 在 `options/Basic.tsx` 增加配置项、恢复默认、清除与冲突提示。
- 增加页面总结快捷键监听模块，在 `entrypoints/page-summary.content.tsx` 安装、随配置变化更新并清理，复用现有手动总结控制器。
- 快捷键变更不重置已生成的总结，也不触发自动总结请求。
