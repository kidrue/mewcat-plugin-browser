# 段落补译设计

用户已确认采用最近块级容器方案，并授权直接执行。

- 鼠标命中的元素沿父链查找，根据实际 CSS display 找到最近的 block、flow-root、flex、grid、list-item、table-cell 或 table-caption；不扩大到 body/html，不以语义标签优先替代布局边界。
- 悬停高亮目标，并提示用户配置的快捷键。高亮层不接收鼠标事件、不改变原页面布局，离开、滚动、失焦、关闭和卸载时移除。
- 鼠标位于 code/pre/kbd/samp、编辑区域、按钮或扩展界面时禁止触发。普通段落内的代码原样保留。隐藏内容和已是目标语言的文本继续过滤。
- 手动补译使用通用提取能力，绕过站点白名单与内容排除，保留代码、编辑器、脚本等保护。复用现有翻译服务、缓存、占位符、错误重试、去重和原文恢复。
- 整页动态刷新合并整页规则与显式补译目标；补译结果不会被误清理，文本变化可更新，移除的目标被清理，关闭翻译可完整恢复。
- 不增加全页漏译扫描，不推断语义段落，不自动翻译悬停目标，不新增依赖，不升级版本、不自动提交。

## 方案取舍

采用用户选择的最近块级容器；放弃基于语义、文本密度和子结构推断最小可读块，避免不可预测的边界。复杂卡片可能整块选中，用户通过高亮预览范围。

## 约束

沿用 Node.js 22.12+、pnpm 10.20.0、现有 WXT/React/TypeScript。测试不调用付费 API，构建使用 build:verify。当前工作区有其他未提交工作，在本工作区内仅编辑本功能文件。
