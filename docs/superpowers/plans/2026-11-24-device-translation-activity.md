# 设备翻译统计实施计划

> **执行技能** superpowers:subagent-driven-development 与 superpowers:test-driven-development。各部分完成后执行验证。

**目标** 统计已授权设备的安装、卸载回执和去重后的整页翻译数量，并在管理员分析页展示。

**方案** 使用已注册的设备身份和签名加密接口。扩展以本地加盐散列生成页面标识，服务端按设备和标识在查询日期范围内去重。管理员新增独立查询接口，保留现有分析接口结构。

**技术栈** WXT、React、Fastify、Prisma SQLite 与现有设备 SDK。

## 数据范围

- 使用统计由用户显式开启，撤回后停止上报并清除该设备的活动数据。
- 整页译文显示后记录一个页面事件。扩展使用每台设备的随机盐生成页面标识，去掉查询参数和片段。
- 明细只包含设备 ID、时间、页面标识和安装状态。完整 IP、地理位置、域名、URL、原文和译文不进入新统计。内容采集与自动分析的生产配置维持由部署管理员管理。
- 更新与重载不计新安装。卸载回执由 Chrome 在能访问 HTTPS 回执页时触发，服务端令牌只记一次。

- [x] 扩展「关于 → 使用统计」授权与整页渲染上报。验证页面失败、段落、子框架和多个批次的统计边界。
- [x] 管理员「全站概览」展示趋势与指标，「设备画像」展示近 7/30 天网页数和生命周期。验证旧服务器和过期响应。
