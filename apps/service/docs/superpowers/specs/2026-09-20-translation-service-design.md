# mewCat 翻译服务设计

目标：为 chorme-translate 提供可部署的免费 AI 翻译接口，技术栈为 Node.js、TypeScript、Prisma，供应商为硅基流动。按用户的执行偏好直接开发，未提供的部署参数采用可配置默认值。

## 范围和取舍

- Fastify 提供 HTTP API；Prisma 7 + SQLite 保存客户端、公钥、邀请码、防重放记录、限额计数和不含原文的用量记录。面向单节点部署，共享同一数据库的请求必须原子预占额度。
- 采用邀请制登记独立设备密钥，避免公开匿名注册绕过设备限制。通用内置密钥和仅靠 Origin 白名单均不能证明官方客户端身份。后续开放自助注册需要独立身份验证或验证码机制，不预留无保护的注册开关。
- 双向 JWE（RSA-OAEP-256 + A256GCM）封装 ES256 JWS。每次请求签名绑定协议版本、HTTP 方法、路径、时间和随机 nonce；响应签名绑定同一 nonce。服务端和客户端均有独立签名/加密密钥，严格限制算法。
- 首次公钥通过 HTTPS 获取，可固定服务器签名公钥。TLS 仍是必须的基础信任。私钥不内置到扩展包，客户端通过 IndexedDB 持久化不可导出的 CryptoKey。
- 先验证签名和时间，再原子插入 nonce；唯一索引阻止并发重放。nonce 保留时间覆盖整个时间容差窗口。
- 在调用上游之前事务预占设备/IP 的频率和日字符额度、全站日字符和请求额度；上游失败不返还额度，避免利用失败重试绕过预算。限制批量数、总文本长度、响应大小、输出 token、全局并发与超时。
- API Key、模型、系统提示词和上游 URL 由服务端控制，客户端无法改成任意聊天代理。原文和译文不写日志或数据库。IP 使用加盐 HMAC，IPv6 按 /64 合并。
- 标准化错误；通过身份校验后的业务响应加密。无法验证身份时仅返回不含内部细节的普通 JSON 错误。

## 接口

| 路径 | 用途 |
| --- | --- |
| GET /health | 检查数据库连接 |
| GET /v1/keys | 公开协议版本及服务器公钥 |
| POST /v1/clients/register | 邀请码 + 设备公钥 + 持有私钥的签名证明 |
| POST /v1/translate | 加密的单段或批量翻译请求 |
| POST /v1/usage | 加密的本人用量查询 |

管理操作仅通过本机 CLI：生成服务器密钥、签发限时一次性邀请码、列出/撤销客户端、清理过期记录。无需公开管理 API。

## 验收

可从空数据库迁移启动；客户端 SDK 完成注册、签名加密、翻译和响应验签解密。使用真实 SQLite 和真实加密进行集成测试，只替换收费的上游 HTTP 接口。覆盖篡改、错误密钥、跨路由签名、重放/并发重放、过期时间、邀请码复用、撤销、限额并发、上游错误和超时。TypeScript 检查、构建、完整测试均通过；提供配置、部署和扩展端接入文档。

## 边界

任何合法客户端仍可能自动化使用其配额；不能保证公开扩展无法被逆向或绝不被滥用。免费指面向用户的服务策略，供应商模型价格以硅基流动后台为准。全站字符/请求限额并非精确人民币账单上限，需结合供应商账户预算。
