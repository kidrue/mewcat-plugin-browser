# mewCat 阅读体验需求规划

日期：2026-10-16。目标：让普通阅读用户顺利完成开始翻译、阅读和失败恢复。

## 范围与约束

- 排除新增网站阅读偏好体系；保留现有网站规则的快捷操作。
- 沿用 WXT、React、Jotai 和翻译引擎，无新增后端或权限。
- 当前页状态与语言覆盖只保存在页面内；引导完成状态保存在本地。
- 不自动提交、推送、升级版本或发布。

## 技术路径

页面操作使用扩展消息调用内容脚本，读取实际翻译状态；复用现有引擎的重试、清理与缓存。设置定位使用 URL hash。异步操作使用任务序号隔离过期结果。自动与手动总结共用控制器。

### 页面与侧边栏（R01–R04、R06）

- 在共享快捷面板加入当前页操作。Popup 绑定打开时的标签页和 URL，消息仅发送到主框架；内容脚本直接调用本页操作。
- 状态由实际引擎的成功、失败节点和调度器任务计算，区分未开始、翻译中、当前阅读区域已处理、部分失败、不可用，不提供整页百分比。
- 当前页源语言使用内存覆盖值，默认自动检测；通过独立运行时字段传到内置翻译服务、生成式模型和 DeepL 链路，并进入缓存维度。导航后恢复自动检测，不写入全局配置。
- 网站快捷操作复用已有两个网址列表，移除同一域名的相反配置；显示原文只暂停当前页面生命周期内的翻译。明确手动翻译可临时覆盖自动翻译排除规则，原规则保留。
- 划词失败保留原文并重试；网页批量重试仅选择仍连接到 DOM 的失败节点，复用调度器去重，不删除成功译文。
- 清空、源语言改变、模型切换和导航使旧任务序号失效；旧响应不得覆盖新译文或状态。缓存刷新前后都验证任务仍有效。

### 配置与划词（R05、R07–R08）

- 需要 AI 的功能在配置不完整时显示待配置状态和直达入口；开关保留原始偏好，但不可用时不显示为正在生效。
- 图片翻译直接定位到图片设置，其他 AI 功能定位到翻译服务；设置页通过 URL hash 支持定位、前进和后退。
- 划词关闭时禁用相关设置，仅圆点模式展示点击或悬停选项；每种触发方式展示具体操作说明。
- 固定划词面板后保留选区快照，新划词与外部点击不覆盖结果；显式关闭或 Escape 解除固定。面板限制高度并支持滚动，复制显示成功或失败反馈。
- 设置页品牌区压缩为简洁状态区域，保留现有蓝白视觉语言与窄屏布局。

### 使用引导与总结（R09–R10）

- 首次打开 Popup 展示可跳过引导：选择目标语言、网页翻译和划词的使用方式。默认服务无需 API Key，不自动打开标签页。
- 完成或跳过状态保存在扩展本地存储，按开发/生产命名空间隔离；设置页可重新查看。保存失败可见，不误记为完成。
- “总结本页”与自动总结开关独立，复用内容提取、模型选择、提示词和渲染。自动与手动触发共享控制器，同一页面待处理请求去重；手动触发会打开结果面板。
- 保留总结禁用网站规则，正文不足、模型缺失和请求失败都有明确反馈；取消与页面导航后的旧响应不更新结果。
