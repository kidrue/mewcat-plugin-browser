# 侧边栏粘贴后自动翻译

状态：已获用户确认，已实现；完整检查、验证构建与 Windows 浏览器粘贴验收通过。

## 行为

- 在侧边栏输入框通过 macOS `⌘V`、Windows `Ctrl+V`、右键或浏览器菜单粘贴文本后，自动翻译粘贴完成后的输入框全文。
- 保留浏览器原生插入行为：在光标处插入，或替换选中的文本；不将已有全文意外覆盖。
- 点击现有“粘贴”按钮仍用剪贴板文本替换全文，并自动翻译。
- 空白内容不发送请求；普通手动输入不自动翻译。手动翻译按钮及 `Ctrl+Enter` / `⌘Enter` 仍可使用，提示文案同时说明两种系统。
- 使用侧边栏当前源语言、目标语言及已选择的翻译服务。新粘贴覆盖旧请求的显示资格，旧结果不得覆盖新结果；每次有效粘贴只触发一次翻译。
- 翻译失败保留已有错误反馈及手动重试方式；剪贴板读取失败保留原提示。

## 可行性和技术选择

现有 `src/sidepanel/index.tsx` 已具备统一翻译服务、请求版本隔离和剪贴板读取按钮，无需修改后台、Manifest 权限或依赖。

推荐原生 `paste` 事件配合插入完成后的输入值，复用统一翻译入口。快捷键监听需要分别处理修饰键，且无法覆盖右键粘贴；对所有 `onChange` 自动翻译会额外触发普通打字请求，因此这两种方案不适合本需求。
