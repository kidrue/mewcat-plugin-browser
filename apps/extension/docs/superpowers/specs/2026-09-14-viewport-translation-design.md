# 按阅读范围翻译

用户已于 2026-09-14 确认本设计。仅影响沉浸式翻译，新增 `enableViewportTranslation`，默认 `false`。

开启后，只发送当前屏及上、下各一屏内的完整文本块。范围以实际滚动容器高度计算；隐藏、断开连接或被祖先裁剪的内容不作为可视内容。优先当前屏，再按滚动方向、距离、DOM 顺序选择任务。当前屏保持 DOM 阅读顺序。

滚动速度达到每秒两屏时暂停新请求，连续 200ms 无滚动后恢复；已发送请求允许完成并缓存。发送前重新检查范围、暂停状态和会话有效性。任务统一去重，失败不因滚动自动重试；显式重试仍遵守范围限制。缓存命中不发送请求。

使用 IntersectionObserver 维护候选集，滚动事件采样方向和速度；几何复核处理嵌套滚动容器和布局变化。不在每次滚动时遍历全文。无 IntersectionObserver 时采用节流的几何检查。

新调度器负责候选任务、缓存准备、批次选择、并发与请求速率、生命周期。ImmersiveTranslator 保留提取、缓存键、请求服务、译文渲染职责。开关切换复用已完成及请求中的内容；关闭模式恢复全页调度范围。关闭翻译、刷新及销毁须停止监听、定时器和过期结果回写。

此模式跳过沉浸式翻译中的额外全文摘要生成（当前调用未使用该摘要），保留页面标题，独立页面总结不变。默认关闭时保留旧流程。

不新增权限、依赖、外部接口。所有 src 修改执行 pnpm format。验证范围边界、滚动暂停恢复、动态排序、异步缓存竞态、缓存命中、失败重试、动态 DOM、嵌套容器、开关切换及生命周期，并运行 pnpm check。
