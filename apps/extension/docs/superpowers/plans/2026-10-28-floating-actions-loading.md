# 悬浮入口与翻译加载状态实施计划

目标：按已确认方案，在网页翻译按钮下增加“打开侧边栏”，设置入口改为“进入高级设置”；只在实际请求翻译时显示 loading，并跳过已经是目标语言的段落。

架构：沿用 React 悬浮控制器与后台消息通道；后台在用户点击消息到达后立即调用 sidePanel.open。DomSelector 按段落筛选目标语言，ImmersiveTranslator 统一追踪实际请求，控制器订阅请求状态。

技术栈：WXT、Chrome MV3、React、TypeScript、Vitest。
