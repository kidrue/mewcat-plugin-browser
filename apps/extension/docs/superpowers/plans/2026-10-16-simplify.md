## Decisions

- 原工作区已有用户改动，直接保留并在当前工作区执行，不搬移或提交。
- 以既有行为测试和新增的 6 项契约测试验证等价重构；不为制造失败而改变正确行为。
- 统计字段兜底不做精简：Zod 运行时解析虽有默认值，项目当前类型推断仍标记字段可选；保留原代码避免削弱类型安全。
- 独立审查未发现行为回归。未评判范围为此前 GitHub 链接工作、`.codex` 配置及本轮未修改的既有逻辑。
- 全量验证重复遇到 `select-search` 原有的即时焦点断言竞态；确认 Floating UI 在下一帧执行初始聚焦后，将该断言改为 `vi.waitFor` 等待实际焦点。断言内容及产品实现不变，不放宽项目超时。
