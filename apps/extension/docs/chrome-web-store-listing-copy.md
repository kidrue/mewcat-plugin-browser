# mewCat Chrome 扩展商店中文文案

供维护 Chrome Web Store 的简体中文商品资料时使用。当前扩展版本与自动发布流程见[发布手册](chrome-web-store-automation.md)。

## 名称

```text
mewCat 译趣喵 - 网页翻译与双语阅读
```

## 简短说明

以下为扩展包中的摘要，来自 [wxt.config.ts](../wxt.config.ts)。

```text
网页双语翻译、划词翻译和图片翻译，支持 Google、Microsoft 翻译及自定义 AI 模型，轻松阅读外语文章、技术文档与海外资讯。
```

## 详细说明（完整替换后台原文）

仅复制以下代码块内的正文到 Chinese (China) 的详细说明字段。

```text
mewCat（译趣喵）是一款网页翻译工具，帮助你对照原文和译文阅读外语内容。

在当前页面中查看译文，尽量保留原有排版；也可处理指定段落，或选中文字查看对应译文。配置视觉模型后，还能识别网页图片中的文字并展示结果。

默认服务无需填写 API Key。你可以在设置中切换服务、选择目标语言、调整译文样式和网站规则。使用自定义模型、图片识别、文章总结或概念解释，需要配置相应模型及 API Key，服务商可能按其规则收费。

处理内容时，相关文本或图片会发送给所选服务。使用 mewCat 内置通道时，文本会经该服务转交供应商处理。需要网络连接，服务可用性和处理效果受网络、模型能力及网页结构影响。
```

## 商店后台维护

1. 在开发者后台打开该扩展，进入商品详情的 Chinese (China) 语言版本。
2. 将「详细说明」完整替换为上方正文，检查预览中没有遗留的关键词行，然后保存。
3. 按后台提供的操作入口重新提交审核；如要求先撤回或处理被拒版本，依照该页面提示操作。
4. 在后台检查提交状态和审查结果。商品详细说明可在后台独立更新，自动发布流程负责上传扩展包并提交审核。

## 官方依据

Google 要求文案清楚准确地说明产品用途，禁止在说明中加入无实质价值的关键词列表和不自然的重复。

- [商品信息与关键词政策](https://developer.chrome.com/docs/webstore/program-policies/listing-requirements)
- [商店违规排查指南](https://developer.chrome.com/docs/webstore/troubleshooting)
