# mewCat 本地验收页面

页面自身的检查结果与待验收项见 [验证记录](VERIFICATION.md)。

在项目根目录运行：

```bash
pnpm example
```

使用已安装或已加载 mewCat 的 Chrome 打开 <http://127.0.0.1:4173>。服务仅监听本机，按 Ctrl+C 停止。端口占用时，PowerShell 可运行 `$env:PORT=4174; pnpm example`。

开发版扩展使用 `pnpm dev` 启动，并在 Chrome 扩展管理页加载对应的 `.output/chrome-mv3` 目录。请以实际 WXT 输出目录为准。允许扩展访问验收站点，在扩展设置中配置翻译服务和目标语言。图片翻译、页面总结分别需要支持对应能力的服务或模型。

页面不读取扩展配置或 API Key，不主动请求翻译，不检测扩展安装状态。真实翻译由扩展发起，遵循所选服务的额度与计费规则。素材和脚本全部在本地，不需要 CDN。页面不随扩展打包。

## 验收顺序

先清空页面的验收记录。建议使用默认站点规则、目标语言简体中文，并记录是否启用了自动翻译。每个场景操作完毕后，人工核对预期并勾选；刷新会保留勾选，切换模型或版本后应清空重测。

| 场景       | 操作                                                           | 验收标准                                                                         |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 沉浸式翻译 | 开启整页翻译，检查正文、列表、表格及链接，再恢复原文并重新翻译 | 内容完整，结构可读，链接可用，没有重复译文，原文可恢复                           |
| 划词翻译   | 按配置的触发方式选择单词、整句、跨行内容，关闭面板后重试       | 结果对应选区，面板可正常打开和关闭                                               |
| 多语言     | 翻译日语、法语、德语及中英混合段落                             | 含义正确，无乱码，数字、时间与产品名保真                                         |
| 动态内容   | 整页翻译开启后追加两次，再替换、重置、追加                     | 新内容得到翻译，旧译文不残留，不重复插入                                         |
| 图片翻译   | 配置图片服务，使用悬浮按钮或右键菜单翻译本地 PNG               | 标题、时间和三条说明识别正确，译文展示完整                                       |
| 页面总结   | 配置总结模型并触发扩展页面总结                                 | 正常返回，覆盖主要内容，不将 240 次到访误写为 240 名访客，不将建议误写为既成事实 |

动态内容重置仅重置测试素材，不清除扩展缓存或页面的人工勾选。不同翻译服务的措辞可以不同，以语义和交互表现验收。页面总结处理整页，可能包含其他测试段落；文章事实清单用于核对，不要求每次输出都包含全部事实。

本页仅覆盖普通 DOM、同源 PNG 与动态 DOM 更新。不覆盖跨域图片、防盗链、Canvas Hook、iframe、Shadow DOM 或服务限流。需要验证服务错误时，可在扩展设置中配置不可用的测试服务，手动观察错误和恢复行为。
