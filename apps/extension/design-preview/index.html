三个方向，同一套真实界面

每个方向都渲染了完整的设置页四个分类（含 20+ 控件的翻译服务页）和模拟真实网页上的悬浮球四种状态。控件都能点，tab 能切，悬浮球能循环状态 —— 不是色板演示。

三份预览都是单文件、零依赖、不请求任何远程资源，字体全部走系统栈，所以你看到的就是这台机器上的真实渲染结果。

譯
方向 A

宣纸朱印

翻译是「落定文本」。设置页是典籍的目录与注解，悬浮球是一枚朱砂印 —— 开启翻译＝盖章。

  • 字体中文宋体做标题，无衬线做正文，等宽做机器值
  • 结构书脊式竖排目录 + 骑缝线 + 朱砂方标记
  • 动作落印：下压 + 墨渍扩散 + 浮出「已」
  • 深浅亮色，长时间读表单不累

风险：米白＋衬线＋红是当下 AI 生成设计最常见的一套。用三处差异拉开 —— 中文宋体而非西文 serif、偏冷朱砂而非土陶橙、印/骑缝线而非 hairline 网格。请重点检验这条是否成立。

方向 B

夜航终端

插件是一台常驻的机器。顶部状态栏永远告诉你它此刻在用什么，悬浮球是一颗猫眼。

  • 字体等宽承载全部机器值，中文一律无衬线
  • 结构vim 式状态栏 + 键···值对齐 + 进程表模型清单
  • 动作瞳孔宽度即状态：细缝 → 收缩 → 全开
  • 深浅强制深色，没有浅色版本

代价有两个：等于放弃浅色（要浅色就得做两套 token）；深色球落在白底网页上是硬割裂的 —— 场景二那一屏请重点看。

方向 C

硬边橙

把品牌橙放到最大。零圆角、粗黑边、硬投影、零模糊。投影＝可按下，按下时投影归零并位移。

  • 字体靠 800/900 字重建立层级，非字号
  • 结构黑条分节标题 + 白块内容，像排版海报
  • 动作物理按压，动效全走 steps() 而非 ease
  • 深浅亮色，保留并放大现有品牌橙

三个方向里执行难度最高。已做三处克制（投影只给可按下的、行分隔线降到 1px 淡色、橙不做大面积文字底），但翻译服务页仍是最吵的一屏 —— 觉得吵就该否掉，这正是做预览的目的。

建议这样看

  1. 先开「翻译服务」页。那是最密的一屏，20+ 控件。设计语言在轻页面上都好看，只有在这一页才见真章。
  2. 再看场景二的悬浮球。它要落在别人的网页上，不是自家地盘。看它是否既能被找到、又不抢正文。
  3. 点一遍悬浮球的三个状态。静止 → 翻译中 → 已翻译。看状态变化是否一眼可辨，不用读文字。
  4. 用 Tab 键走一遍。三个方向的 focus 环用色是不同的设计决策（C 刻意用蓝而非橙，因为橙已经是选中态）。

可以混搭

  • 不必整选一个。比如「A 的设置页 + C 的悬浮球」是成立的组合 —— 设置页要久读所以安静，悬浮球要被找到所以张扬。
  • 也可以只取局部：B 的状态栏（不进任何页面就知道当前配置）可以嫁接到 A 或 C 上。
  • 觉得三个都不对也是有效结论。告诉我哪里不对，比选一个勉强的更有用。
